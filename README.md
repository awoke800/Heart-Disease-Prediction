Heart Disease Prediction System

A machine learning-based web application that predicts the likelihood of heart disease using patient health data.
The model was trained using the Heart Disease UCI dataset and deployed with Streamlit for real-time predictions.

Technologies Used:
Python
Pandas
Scikit-learn
Streamlit
Joblib
Features:
Data preprocessing and cleaning
Random Forest classification model
Real-time prediction interface
User-friendly web dashboard
